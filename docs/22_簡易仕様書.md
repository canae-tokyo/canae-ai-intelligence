# CANAE AI Intelligence 簡易仕様書

## 1. サービス概要

CANAE AI Intelligenceは、AI企業、AIツール、モデル、ニュース、公開ベンチマーク、CANAE独自評価を整理・可視化する情報基盤です。

```text
正式URL：
https://canae-ai-intelligence.canae-tokyo.workers.dev

運用状態：
Production / Public Search Release完了

管理主体：
canae.tokyo@gmail.com
```

## 2. 公開画面

| URL | 内容 |
| --- | --- |
| `/` | ダッシュボード、重要ニュース、注目ツール、ランキング |
| `/news` | Verifiedニュース一覧 |
| `/genre/model` | 総合AI・基盤モデル |
| `/genre/coding` | コーディングAI |
| `/genre/image` | 画像生成AI |
| `/genre/video` | 動画生成AI |
| `/genre/audio` | 音声AI |
| `/genre/agent` | AIエージェント |

公開ページはGoogle検索向けに`index, follow`設定済みです。

## 3. 内部管理画面

```text
/internal/review-candidates
```

内部管理画面はCloudflare Accessで保護されています。

- 許可アカウント：`canae.tokyo@gmail.com`
- 未認可ユーザー：Accessログインまたは拒否
- 検索エンジン：`noindex, nofollow`
- 公開ナビゲーション：導線なし

## 7. 公開条件

公開画面へ表示する条件は次のとおりです。

| データ | 公開条件 |
| --- | --- |
| ツール | `dataStatus: verified` |
| ニュース | `status: verified` |
| ベンチマーク | `dataStatus: verified` |
| CANAE評価 | `reviewStatus: approved` |

`draft`、`archived`、`pending`、`rejected`は公開対象外です。

## 8. 更新フロー

```text
公式情報収集
  -> 候補生成
  -> 重複・差分確認
  -> 候補登録
  -> Review UIで人手承認
  -> Promotion plan生成
  -> GitHub PR自動作成
  -> 人が内容とCIを確認
  -> Squash Merge
  -> Production反映
```

自動化はPR作成までです。mainへの自動mergeは行いません。

## 9. 検索公開

- 公開8ページ：インデックス許可
- `robots.txt`：公開済み
- `sitemap.xml`：公開8ページを登録
- canonical：正式URLへ統一
- Google Search Console：登録・所有権確認済み
- `/internal/*`：検索対象外
- Preview URL：`noindex`維持

## 10. セキュリティ

- 内部画面はCloudflare Access必須
- Worker側もFail-closed
- JWT、Cookie、GitHub tokenは公開HTMLへ出力しない
- GitHub Promotion tokenはCloudflare secretで管理
- D1監査情報は公開しない
- 公開ページと内部ページを明確に分離

## 11. 変更禁止事項

次は事前承認なしに変更しません。

- 正式Production URL
- Cloudflare所有アカウント
- GitHub repository
- Cloudflare Access設定
- D1 database
- mainへの自動merge禁止方針
- 公開ベンチマークとCANAE評価の分離
